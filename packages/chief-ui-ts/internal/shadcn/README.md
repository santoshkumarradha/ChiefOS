# Internal Shadcn Scaffold

This directory is the attribution and quarantine point for any copied shadcn/ui
source used as Chief OS scaffolding.

Rules:

- MIT attribution stays in this directory and any copied source file.
- Copied source is treated as internal starter material, not a public dependency.
- Public exports from `@chief-os/ui` must never expose shadcn or Radix names.
- Any copied component must be re-themed with Chief tokens before use.
